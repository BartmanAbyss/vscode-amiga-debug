# NDK 3.2R4 sys-include for m68k-amiga-elf GCC toolchain

Drop-in replacement for the NDK 3.9 based `sys-include` bundled with the
[BartmanAbyss/vscode-amiga-debug](https://github.com/BartmanAbyss/vscode-amiga-debug)
toolchain, updated to AmigaOS NDK 3.2R4.

## Contents

- `sys-include/` — ready-to-use headers, point your NDK path here
- `sys-include/ks13_compat.h` — compile-time KS 1.3 compatibility guard (see below)
- `gen_proto_inlines.sh` — generates `inline/`, `proto/`, `clib/` headers from NDK 3.2R4 SFD files using sfdc
- `fix_sfdc_quirk.sh` — fixes sfdc's `#define *FuncName` pointer return type quirk in generated inline headers
- `gen_ks13_compat.py` — generates `ks13_compat.h` from NDK 3.2R4 SFD version tags

## How to use

Point your compiler at the `sys-include` folder:

```bash
m68k-amiga-elf-gcc -I/path/to/ndk32r4/sys-include ...
```

Or in a Makefile:

```makefile
NDK = /path/to/vscode-amiga-debug/ndk32r4/sys-include
CFLAGS += -I$(NDK)
```

## KS 1.3 compatibility guard

When building software that must run on Kickstart 1.3, include `ks13_compat.h`
to get a compile-time **error** if you accidentally call a function that does
not exist in KS 1.3 (version 33):

```c
#include <ks13_compat.h>   /* add this when targeting KS 1.3 */
#include <proto/exec.h>

void test(void)
{
    AllocMem(100, 0);   /* fine — exists since KS 1.2                       */
    AllocVec(100, 0);   /* error: attempt to use poisoned 'AllocVec'        */
}
```

`ks13_compat.h` uses `#pragma GCC poison` to mark 492 functions across all
NDK 3.2R4 libraries that require KS 2.0 (version 36) or later. It is
generated automatically from the `==version` tags in the NDK 3.2R4 SFD files
by `gen_ks13_compat.py`.

## How it was generated

1. Download NDK 3.2R4 from Aminet: https://aminet.net/package/dev/misc/NDK3.2
2. Get sfdc (already a Perl script, no compilation needed): https://github.com/adtools/sfdc
3. Run `gen_proto_inlines.sh` pointing at the NDK 3.2R4 `SFD/` folder
4. Run `fix_sfdc_quirk.sh` to fix pointer return type in generated macro names
5. Copy `macros.h` and `stubs.h` from the existing Bartman installation:
   `bin/<platform>/opt/m68k-amiga-elf/sys-include/inline/`
6. Copy raw NDK 3.2R4 struct headers (`exec/`, `devices/`, `libraries/` etc.)
   from NDK 3.2R4 `Include_H/` directly
7. Run `gen_ks13_compat.py` to generate `ks13_compat.h`:
   ```bash
   python3 gen_ks13_compat.py /path/to/NDK_3.2/SFD/ > sys-include/ks13_compat.h
   ```

## Differences from the bundled NDK 3.9 based headers

- Updated to AmigaOS 3.2R4 (released on March 8, 2022 by Hyperion Entertainment)
- Generated by sfdc 1.12 (vs sfdc 1.11 in the original)
- Includes new APIs added in AmigaOS 3.2 (trackfile.device, new exec/dos functions etc.)
- Same `macros.h` with explicit `asm("a6")` constraint for GCC 8+ / GCC 15.x compatibility
- Adds `ks13_compat.h` for compile-time KS 1.3 safety checking

## Tested with

- `m68k-amiga-elf-gcc` 15.1.0 with `gcc-barto.patch` and `gcc-regparm.patch` applied
- SimpleDevice device driver compiled and linked successfully
- `ks13_compat.h` correctly poisons KS 2.0+ functions at compile time
